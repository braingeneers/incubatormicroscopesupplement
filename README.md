# incubatormicroscopesupplement

Supplemental material for the paper "A Modular In-Incubator Microscope for Longitudinal Live Cell Microscopy" by Drew Ehrlich, Yohei Rosen, Santhosh Arul, John Minnick, Seth Nicholson, Kateryna Voitiuk, Spencer Seiler, Anna Toledo, Samira Vera-Choqqueccota, Neil Doherty Jess Sevetson, Max McGlynn, Kivilcim Doganyigit, Maryam Moarefian, Sri Kurniawan, Mohammed A. Mostajo-Radji, Sofie R. Salama, Ethan Winkler, David Haussler, and Mircea Teodorescu.

## File Reference
CAD/CNC/ - 3D CNC parts for the microscopy system.

CAD/flatparts - CAD files for parts that can be milled on a CNC router

CAD/flatparts - CAD files for completed assemblies to be used as visual aids.

code/ - code for programming and operating the microscope in various configurations as shown in the manuscript

data/ - contains the source data for the thermal validation experiment described in Section 2.2.1 of the manuscript
